# 🚀 Construindo um Layout Responsivo Para o Site do Discord Com CSS

Um projeto prático focado na criação de um layout moderno e responsivo, aplicando conceitos essenciais de HTML e CSS para reproduzir a interface do Discord.

---

## 🚀 Acesse o Projeto Online

🔗 **Visualizar no GitHub Pages:**  
https://luis-gustavo23.github.io/Construindo-um-Layout-Responsivo-Para-o-Site-do-Discord-Com-CSS/

---

## 📌 Descrição

Este projeto consiste na construção de um layout responsivo inspirado na página inicial do Discord, utilizando **HTML5** e **CSS3**, com foco em:

- Estruturação semântica
- Uso de Flexbox
- Responsividade com Media Queries
- Boas práticas de organização de código
- Fidelidade visual ao layout proposto

O objetivo principal é praticar conceitos fundamentais de desenvolvimento front-end moderno.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries

---

## 📱 Responsividade

O layout foi desenvolvido com abordagem responsiva, adaptando-se para:

- 💻 Desktop
- 📱 Tablets
- 📲 Dispositivos móveis

Principais técnicas aplicadas:

- `flex-direction` dinâmica
- `column-reverse` em seções específicas
- Redução proporcional de tipografia
- Ajustes de padding e espaçamento
- Imagens com `max-width: 100%`

---

## 🏗️ Estrutura do Layout

### 🔹 Header
- Background com imagem responsiva
- Título centralizado
- Texto descritivo
- Botões de ação estilizados

### 🔹 Seções
- Alternância de layout (imagem + texto)
- Seções com largura máxima controlada
- Seções full-width com background diferenciado

### 🔹 Footer
- Fundo escuro
- Centralização do logo

---

## ✨ Conceitos Aplicados

- Reset básico com `*`
- `box-sizing: border-box`
- Organização por classes específicas
- Separação entre seções centralizadas e full-width
- Uso estratégico de `gap`
- Tipografia responsiva
- Mobile-first adaptations via media query
